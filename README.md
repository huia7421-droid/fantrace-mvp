# NamtanFilm 行程與活動後內容

把 NamtanFilm（Namtan Tipnaree × Film Rachanun）的活動行程，和活動結束後粉絲在各平台發布的內容，整理成一頁。

這是 FANTRACE 的早期試作頁，**只在邀請期間開放**，不對外宣傳。

---

## 這是什麼

- **行程區** — 已公告、還沒發生的活動（日期時間一律換算成台灣時間）
- **內容區** — 活動結束後的飯拍、站姊拍、官方照片、粉絲翻譯，共 51 筆、涵蓋 9 場活動
- 可以按**人物**、**內容類型**、**翻譯種類**、**活動**、**拍攝者**篩選

目前收錄的範圍是 2026/09/18 – 2026/10/10。

## 這不是什麼

- **不是轉載站。** 頁面只放**連結**，不下載、不重新上傳任何人的照片或影片。所有內容都會導回原作者的貼文
- 不是官方帳號，和 GMMTV 或藝人本人無關
- 沒有登入、沒有留言、沒有會員
- 不收集內容。所有連結都是人工蒐集的公開貼文


| | |
|---|---|
| 前端 | 單一 HTML，資料以 JS 常數內嵌 |
| 託管 | GitHub Pages |
| 字型 | Google Fonts（IBM Plex Sans / Mono） |

## 資料結構

兩組陣列，以 `ev` 欄位關聯（一場活動對多筆內容）。

### `EVENTS`

| 欄位 | 說明 |
|---|---|
| `id` | `E01`–`E09` |
| `date` / `time` | **台灣時間**（原始時區記錄在資料整理階段，此處已換算） |
| `title` | 活動名稱。同一天多場會加「（彩排）」「（正式）」區分 |
| `online` | `true` 線上 / `false` 線下 |
| `venue` | 線下為場地，線上為平台名 |
| `artists` | 陣列，**只放真人**（Namtan / Film / Milk / Love / View / Mim） |
| `tags` | 非真人標籤，例如 Lunar（NamtanFilm 設計的吉祥物） |
| `type` | 直播／代言活動／訪談／見面會／簽售／彩排／接機 |
| `cp` | Namtan 與 Film 是否同時出席 |
| `src` | 官方公告連結。接機、彩排沒有公告，此欄為空 |

### `CONTENTS`

| 欄位 | 說明 |
|---|---|
| `id` | `C01`–`C51` |
| `ev` | 對應 `EVENTS.id` |
| `pf` | 平台 |
| `ct` | 飯拍影片／飯拍照片／站姊拍／官拍／品牌方拍／粉絲翻譯／平台字幕 |
| `who` | 作者帳號 |
| `url` | 原貼文連結（已移除追蹤參數） |
| `date` / `time` | 發布時間（台灣時間） |
| `prec` | `exact` 精確到分／`approx` 原記「左右」／`date_only` 只知日期，`time` 為空 |
| `hrs` | 發布時間距離活動開始幾小時 |
| `subj` | 拍到誰 |
| `cap` | 文案裡是否含翻譯 |
| `tr` | 翻譯者帳號 |

### 三種「翻譯」是不同的東西

| | 怎麼表示 | 性質 |
|---|---|---|
| 完整翻譯 | `ct = 粉絲翻譯` | 人工翻譯整場，多在 bilibili |
| 文案有翻譯 | `cap = true` | 飯拍發布者把對話打在文案裡，片段式 |
| 平台字幕 | `ct = 平台字幕` | 平台自動產生 |

頁面上三者分開標示、可分別篩選，因為它們的即時性和完整度差很多。

## 怎麼更新內容

資料直接寫在 `index.html` 的 `EVENTS` / `CONTENTS` 裡。更新方式：

1. 在本機編輯 `index.html`（**用純文字編輯器，不要用 Word**）
2. 上傳覆蓋到這個 repo
3. 等 1–2 分鐘，GitHub Pages 會自動重新發布

新增活動時，若 `start_date_tw` 是未來日期，會自動出現在行程區；過去的活動會從行程區消失，但內容仍保留在內容區。

## 隱私

頁面會記錄**哪些連結被點了**，用來了解哪一類內容比較有用。每一筆紀錄包含：邀請連結的編號、點了什麼、什麼時候、手機或電腦。

**不會**記錄姓名、email、IP、精確位置，也沒有任何第三方分析服務或廣告追蹤（頁面只載入 Google Fonts 一個外部資源）。

紀錄存放在一個獨立 Google 帳號的試算表，權限僅限專案成員，試作結束後刪除。

不想被記錄的話，用不帶編號的網址開啟就可以 —— 內容完全一樣。
